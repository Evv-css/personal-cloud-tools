Privacy Policy

Last updated: October 25, 2026

Overview

Personal Cloud Tools is a personal utility project designed to help manage files stored in cloud services.

Google Drive Access

The application may request read-only access to Google Drive files with the user's authorization.

Data Usage

Authorized file data is accessed solely to provide the application's file management functionality.

Data Storage and Sharing

OAuth credentials may be stored securely to maintain authorized access. File data is not sold or shared with advertisers.

Data Retention and Deletion

Users can revoke access through their Google Account security settings. Locally stored credentials and cached data can be deleted by the application operator.

Contact

For privacy inquiries, contact the application developer using the support email listed on the Google OAuth consent screen.
